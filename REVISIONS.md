# Revisions

Changes made to published pages after their publication date, newest first.
Append to this file; it does not need a decision each time.

**Which changes go where.** A change to a published figure, a quotation or a
conclusion gets a visible note on the page itself, because a reader may have
relied on the old version. A change to method, wording or structure is recorded
here and nowhere else. If it is not obvious which kind a change is, ask before
deciding.

**The test is whether a reader could have acted on it.** The rule covers figures
a reader might use, not figures describing the work itself. A change to the 1.5x
ratio or to a quoted NERSA figure needs a note, because someone may have put it
in a model or a decision. A change to how many figures the cross-check covers
does not, because nothing downstream of the page turns on it, and in that case
it moved toward more verification rather than less.

This file is excluded from the built site in `_config.yml`, alongside the
working draft. It is a repository record, not a page.
